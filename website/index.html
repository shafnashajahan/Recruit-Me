CAPABILITIES

Everything you need to move
from resume to opportunity.

One lightweight platform for recruiters, developers, and job seekers.

01

Resume–Job Matching

Upload one or more PDF resumes and compare them with a target job description using skill-based matching.

02

Skill Gap Detection

See which skills are already present and which job requirements are missing from a candidate profile.

03

AI Interview Questions

Generate technical, project, and behavioural interview questions from the candidate and role context.

04

ATS-Friendly CV Builder

Enter candidate details and a target job description to create a tailored CV and download it as a PDF.

05

Vector Index (FAISS)

Resume and job text can be embedded into a FAISS vector index to support future retrieval and ranking features.

06

Privacy by Design

The project is designed around temporary resume processing, with uploaded PDF data excluded from version control.
