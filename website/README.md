# Recruit-Me Website

Static landing page for the Recruit-Me AI recruitment project.

## Deploy with GitHub Pages

This website is designed to live inside the main `Recruit-Me` repository under `website/`.

1. Copy the contents of this folder into `Recruit-Me/website/`.
2. Commit and push to `main`.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. The included workflow deploys the `website/` folder.
6. Your site will be available at:

https://shafnashajahan.github.io/Recruit-Me/

The AI Streamlit application remains separate because it requires Python and an LLM runtime.
